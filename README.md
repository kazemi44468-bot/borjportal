# برج پورتال
پلتفرم یکپارچه مدیریت دیجیتال برج‌ها و مجتمع‌های ساختمانی.

## ساختار
- `index.html`: معرفی پلتفرم
- `platform.html`: معرفی معماری و خانواده محصولات
- `services.html`: سبد خدمات و ماژول‌ها
- `towers.html`: فهرست برج‌های عضو
- `towers/negin-piroozi.html`: نمونه نمایشی برج نگین پیروزی
- `architecture.html`: معماری فنی و راهبرد هوشمندسازی
- `contact.html`: ارتباط و درخواست همکاری
- `assets/css/style.css` و `assets/js/app.js`: پوسته مشترک

## انتشار
در GitHub از مسیر Settings → Pages، شاخه `main` و پوشه `/ (root)` را انتخاب کنید.
این نسخه یک وب‌سایت استاتیک و نمونه نمایشی محصول است؛ اتصال به پایگاه داده، درگاه پرداخت، احراز هویت واقعی و تجهیزات IoT نیازمند پیاده‌سازی سمت سرور و زیرساخت امن است.
